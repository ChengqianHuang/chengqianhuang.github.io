# 风屿 Wind Isle

站内第一款 3D 角色动作游戏。 Three.js 卡通渲染（赛璐璐色阶、背面外扩描边、菲涅尔边缘光），角色、敌人、场景与音效全部由代码程序化生成，无外部素材、无运行时 CDN。

## 玩法

- 无尽波次竞技场：清波 → 三选一天赋 → 难度递增；每 3 波遭遇三阶段 Boss「风暴之心」，震地后进入可击破的眩晕状态。
- 操作：
  - 移动：WASD / 方向键 / 左侧虚拟摇杆
  - 普攻（三段连击，第三段击退）：`J` / 鼠标左键 / 攻击键
  - 蓄力重击：`U`（按住蓄力，蓄满自动释放）
  - 风刃（短冷却远程）：`K`
  - 大招（能量满后）：`L`
  - 冲刺（无敌帧，可取消攻击）：`空格` / `Shift`
  - 暂停：`P` / `Esc`，切换窗口自动暂停
- 清波结算三选一天赋（共 10 种，各自有叠加上限），无伤清波有额外奖励。最高分与最远波次保存在浏览器本地（`windisle-best`）。
- 减少动态效果偏好会关闭镜头震动、花瓣与部分粒子，保留核心打击表现。

## 开发

```bash
cd windisle
npm ci --ignore-scripts
npm test        # node ../scripts/test_windisle.mjs
npm run build   # esbuild 打包到 dist/windisle.js，与源码一起提交
```

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/engine.mjs` | 纯规则引擎：战斗数值、连击窗口、无敌帧、预警区判定、波次编成、天赋池、Boss 阶段。无 DOM、无渲染依赖，给定种子完全可复现，供测试直接导入 |
| `src/player.mjs` | 主角装配与程序化动画（待机/奔跑/三段斩/蓄力/冲刺/受击），朱红飘带用 verlet 链做次级运动 |
| `src/enemies.mjs` | 四种魔物与 Boss 的造型装配，姿态由引擎相位驱动；受击闪白、阶段变色 |
| `src/world.mjs` | 场景：草甸竞技场、崖壁、瀑布、浅池、实例化风摆草与花、浮空岛、天空穹顶、云与光照 |
| `src/art.mjs` | 卡通渲染核心：4 阶渐变映射、边缘光注入、描边壳、径向/云朵贴图 |
| `src/fx.mjs` | 特效：地面预警贴花、刀光弧、冲击环、火花、尘土、花瓣、伤害数字、镜头震动与命中停顿 |
| `src/ui.mjs` | HUD、波次横幅、天赋三选一、暂停/结算对话框、触屏控件显隐 |
| `src/audio.mjs` | WebAudio 合成音效与环境风声，无音频文件 |
| `src/main.mjs` | 启动、固定步长主循环、命中停顿、第三人称相机、键鼠/触屏输入、后期 bloom |

渲染层（player/enemies/world/fx/ui/audio）只读取引擎状态与事件，不回写规则数据；事件由主循环每帧消费后清空。

## 测试与联调

- `scripts/test_windisle.mjs`：种子 RNG 覆盖连击伤害序列（12/14/22 循环）、第三段击退、冲刺/受击无敌帧、冲撞兽直线预警判定、Boss 眩晕易伤与阶段阈值、波次预算与出怪安全距离、天赋互异与上限、蓄力重击/风刃冷却/大招清场、机器人完整对局、同种子可复现、暂停冻结与站点集成（games.json、页面与封面存在）。
- `games/windisle.html?pump=1`：用定时器驱动帧循环（rAF 被系统节流或窗口被遮挡时联调用）。
- `?pump=1&slow=N`：帧间隔放慢 N 倍（模拟 dt 仍被钳制），用于抓拍特效瞬间；封面 `game-assets/windisle.jpg` 即以此方式从实际渲染截取（720×440 静帧）。
