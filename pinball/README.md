# 黄铜弹珠台 / Brass & Gravity

入口：`/games/brass-pinball.html`。电脑优先，手机也可用屏幕上的三个按钮玩。

- A / D 或左右方向键：左右挡板。
- 按住空格蓄力，松开发射；屏幕中键在待发球时控制发射，在球场内有球时变为轻推桌面。
- W / ↑：轻推桌面。六秒内三次会停机三秒，并取消救球保护。
- Esc：暂停 / 继续；切换标签或窗口自动暂停。
- 每局三颗球。发射后十秒保护；击落左侧三枚铜靶，再打入右侧轨道，触发三球与十二秒保护。多球期间再次完成机关获得轨道大奖。
- 连续两秒内命中弹簧鼓增加连击，最高五倍。最高分保存在 `brass-pinball-best-v1`，无法使用存储时仍可玩。

## 开发

```sh
cd pinball
npm ci --ignore-scripts
npm test
npm run build
```

提交源码时同时提交 `dist/`。运行资源全部随网站提供，不依赖 CDN、远程字体或图像服务。Three.js 使用 MIT 许可证，许可证随构建保存。台面印刷、木纹、网格、轨道、齿轮、钢珠和音效均由代码生成。

`src/physics.mjs` 是独立确定性二维弹珠模拟：240 Hz 固定步长，胶囊轨道碰撞、旋转挡板的接触面速度、等质量球间冲量及最大速度限制。钢珠在桌面上按二维运动；进入高架轨道后沿确定的三维曲线运动，不宣称完整三维刚体解算。可玩碰撞与渲染共享墙、挡板、弹簧鼓、铜靶、齿轮和轨道数据。`src/art.mjs` 只读取规则状态，提供 Three.js 实体模型、PBR 金属、软阴影及生成的反射环境。音频在用户操作后解锁。

## 验证

`node scripts/test_pinball.mjs`（仓库根目录）覆盖蓄力 / 发射、镜像挡板击球、目标解锁、轨道曲线、三球、关闭的入口、救球与三球结束、暂停 / 重开、晃台惩罚、30 / 60 / 120 Hz 一致性、六组各三分钟的普通输入模拟，以及无挡板操作的整局结束。这些模拟是回归检查，不是对真人难度的评估。

浏览器另验：首屏加载、键盘 / 按钮蓄力、暂停与失焦、深浅主题、全屏、1280×800 / 1280×600 / 390×844 / 844×390 的布局。封面从实际游戏场景截图制作。
