# 拆楼公司 / Demolition Co.

入口 `/games/demolition.html`。电脑优先的 3D 物理拆除游戏：六个可自由选择的合同，以及不限弹药的自由拆楼场。鼠标点击建筑开炮，拖动绕场观察，滚轮缩放；手机可点按、拖动与双指缩放。空格向当前目标开炮，1 / 2 换弹，C 恢复视角，R 重开，Esc 暂停。

## 玩法

让指定比例的建筑重量落到黄色验收线以下。统计以高于验收线的初始结构为分母，按质量计算，并使用旋转后的包围盒顶部判断是否低于验收线。蓝色小屋属于保护目标，爆炸和较强的碎片碰撞都会损伤它。有限弹药耗尽后等现场落定再结算；自由模式没有弹药上限，也不判胜负。

破拆弹集中破坏支撑，爆破弹产生较大范围的冲击。木梁、砖、混凝土、钢架、玻璃的耐久和密度不同；黄色爆破桶能够连锁引爆。首次进入不会自动坍塌。对楼体使用显式支撑图：支撑被打断或撞断后，失去所有支撑的构件转为动态刚体。构件、炮弹和地面之间的后续运动、旋转、摩擦与碰撞由 Jolt 计算。楼体由预先划分的块体组成，切口位置来自蓝图。

最后一发命中会短暂放慢时间；也可以手动开关慢动作。每一炮保留最多十秒的变换记录，回放以半速播放并在采样间插值。回放期间物理世界冻结，退出后恢复现场，不消耗弹药、不改变进度与星级。切换窗口、标签页或 Esc 会暂停。最佳星级只保存在当前浏览器的 `demolition-records-v1`。

## 开发与发布

在 `demolition/` 执行：

```sh
npm ci --ignore-scripts
npm test
npm run build
```

从仓库根目录启动静态 HTTP 服务。修改源码后须重建，并将 `dist/` 和源码一起提交；GitHub Pages 直接提供预构建文件。

- `src/levels.mjs`：六个合同、自由模式、材料参数、支撑蓝图和存档校验。
- `src/engine.mjs`：单线程 Jolt WASM、连续炮弹碰撞、结构脱落、连锁爆破、质量进度、保护目标和结算。
- `src/world.mjs`：楼体、工地、吊机、材质、尘土、准星、回放插值和场景资源回收。
- `src/art.mjs`：仓库已有程序化几何与标牌工具的独立副本。
- `src/main.mjs`：鼠标 / 触屏输入、相机、固定 60 Hz 物理步长、声音、菜单与回放。
- `../scripts/test_demolition.mjs`：运行真实 WASM，验证六关的完整解法、弹道、倒塌、失败、重开、自由模式回收及存档。

每关重开复用同一个 WASM 世界，并移除旧刚体。弹丸八秒后回收，自由模式不会随射击次数无限增加物理对象；烟尘使用固定粒子池，回放有固定时长。流畅画质关闭动态阴影并降低像素密度。

## 素材与许可

建筑、施工现场、吊机、地面标线、程序化贴图、界面与合成音效均由 Codex 用代码制作。封面来自实际运行画面。

环境光复用仓库中 `/racing/assets/venice_sunset_1k.hdr`，来自 [Poly Haven / Venice Sunset](https://polyhaven.com/a/venice_sunset)，作者 Greg Zaal，CC0；运行时从本站读取。其余依赖为 [Three.js](https://github.com/mrdoob/three.js) 与 [Jolt Physics.js](https://github.com/jrouwe/JoltPhysics.js/)（MIT），许可随 `dist/LICENSES.txt` 一起部署。无运行时 CDN、外部 API 或后端。
